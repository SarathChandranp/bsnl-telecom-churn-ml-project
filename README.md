# BSNL Customer Churn Analysis

## 📌 Overview

This project predicts customer churn in BSNL telecom services using supervised machine learning algorithms. The goal is to identify customers who are likely to leave the service.

---

## 🚀 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

---

## 📂 Dataset

The dataset contains customer information such as:

- Gender
- Internet Service
- Contract Type
- Monthly Charges
- Tenure
- Payment Method
- Churn Status

---

## 🛠️ Machine Learning Models

- Logistic Regression
- Decision Tree
- Random Forest
- KNN
- SVM

---

## 📊 Project Steps

1. Data Collection  
2. Data Preprocessing  
3. Exploratory Data Analysis  
4. Model Training  
5. Model Evaluation  
6. Churn Prediction  

---

## 📈 Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
